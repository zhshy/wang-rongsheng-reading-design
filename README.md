# 阅读教学设计（王荣生）

> 王荣生《阅读教学设计的要诀》知识库。用“依体式定终点、缘学情明起点、中间搭两三个台阶”设计单篇课文阅读教学。

## 功能

- 设计一篇课文的阅读教学，确定教学目标（教学点）
- 判断某个知识点该不该教，选择教学路径，安排教学环节
- 区分"教的活动"与"学的活动"，准备台阶状教案
- 设计阅读课的检测与评价（测什么维度、选什么题型）

## 核心框架

**依体式，定终点；缘学情，明起点；中间搭两三个台阶。**

**备两头法**：一备教材（循文本体式抓课文关键点，标黄），二备学生（推测评测学生疑难处，标绿）。**黄绿重合处 = 教学点 = 教学目标**。

**三条不可动摇的原理**：

1. 学生在阅读（不是教师在讲自己的理解）
2. 学生的理解感受须有明显变化
3. 作者要表达的，文本中已表达

## 检测设计（本仓库亮点）

**一字之差决定题型**：

> 侧重"**看出**"关键点的意义 → **结果维度**
> 侧重"**看到**"语篇的关键点 → **过程维度**（阅读方法与策略）

| 文本类型 | 理解要点 | 倾向 | 适合题型 |
|---|---|---|---|
| 实用类文本 | 说了什么 | 结果维度 | 反应性测试（可用客观题） |
| 文学类文本 | 怎么说的 | 过程维度 | 表现性测试（**须开放题**） |

用客观题测散文的"怎么说"是本领域最常见的错误。

## 来源

提炼自王荣生《阅读教学设计的要诀（第二版）》（中国轻工业出版社，2021，ISBN 9787518432271）。

**本技能不含原书课例分析文本**，只做学理提炼与提问清单。需要具体课例时请查阅原书第四章。

## 作者立场

王荣生对"大概念"组织单元、大单元教学、群文阅读、项目化学习持**"缓行"**态度——主张先在小范围消化试验，不急于推广。"本书所应对的问题是单篇课文的阅读教学问题。"

使用本技能讨论单元整体设计时，不要把这个立场扭曲为全盘否定，也不要回避他的审慎。

## 安装

```bash
git clone https://github.com/zhshy/wang-rongsheng-reading-design.git
```

将技能目录放入 WorkBuddy 的用户级技能目录：

- **Windows**：`C:\Users\<用户名>\.workbuddy\skills\`
- **macOS / Linux**：`~/.workbuddy/skills/`

重启 WorkBuddy 后生效。

## 什么是 Skill

Skill 是给 AI 助手加载的专业知识包：一个 `SKILL.md` 定义触发条件与工作流程，`references/` 存放按需加载的细节文件。加载后助手会按既定流程工作，而不是即兴发挥。

本仓库技能遵循 Agent Skills 规范：YAML frontmatter + Markdown 正文 + 渐进式披露的 references。
